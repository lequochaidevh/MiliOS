# MiliOS
Build mini OS for MCU.

## Overview

The project will be build a OS, which is small and basic.

---

## Goals

- Clean.
- Reuse.
- Basic.
- Work with MCU stm32F1, which have a litle bit flash ROM.
- Low Layer libraries.
- C code.
